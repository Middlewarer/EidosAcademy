# Лабораторная №1: React в EidosAcademy

Предметная область — образовательная платформа. Это адаптация задания про магазин,
а не реализация торговли. Корзину, цены и оформление заказа не добавляли.
Соответствие такой замены формальным требованиям нужно согласовать с преподавателем.

| Требование | Реализация / где показать |
| --- | --- |
| React SPA | React + React Router, переходы без перезагрузки документа |
| CSS-фреймворк, JS-библиотеки | Bootstrap 5 utilities для flex-раскладки; React Router, react-markdown. Bootstrap подключён без глобального сброса стилей и JS, чтобы сохранить дизайн |
| БЭМ | Новые блоки: `learning-card__actions`, `course-skeleton__line--short`, `learning-helper__panel` и другие. Старые стили целиком не переписывались |
| Гостевой каталог | `/courses`, поиск и фильтры доступны без входа |
| Меню, подвал, навигация | Существующие Header/Footer, новое избранное в меню, мобильное меню |
| Карточки с описанием | Каталог, главная, `/courses/:id` с программой и материалами |
| Динамическая пагинация | Каталог и избранное: по 3, 6 или 12 курсов; страницы пересчитываются при фильтрации, поиск возвращает на первую страницу |
| Предварительный просмотр | Кнопка на карточке: модальное окно с кратким описанием, количеством тем и программой из API. Закрывается кнопкой и Escape |
| Корзина / LocalStorage — адаптация | `/favorites`: добавить/убрать курс, очистить список, счётчик, пустое состояние. Хранятся только ID в `eidos:favorites`, есть синхронизация вкладок. Это список браузера, не аккаунта |
| Количество и общая стоимость — адаптация | Считаются выбранные курсы; дубликаты, число копий и стоимость не нужны для индивидуального обучения. Денежного расчёта нет |
| Оформление заказа — адаптация | Уже существующая запись «Начать обучение» и возврат к курсу. Для сохранения учебного прогресса требуется аккаунт; избранное само по себе не записывает на курс |
| Чат-бот | «Помощь с обучением»: вопросы, ответы, ссылки в каталог, профиль, избранное и обратную связь. Простой справочный бот, не LLM и не живой оператор |
| Хлебные крошки | Каталог, избранное, курс и модуль; ссылки на родительские страницы |
| Карусель | На главной вместо прежнего блока процесса обучения — три переключаемых совета с полезными переходами. Без автопрокрутки |
| Анимация, favicon | Существующий favicon `/lamp.svg`, переходы, анимация skeleton. Учтён `prefers-reduced-motion` |
| Параллакс | Намеренно не добавлен: декоративное движение не помогает чтению учебных материалов. Если это обязательный отдельный пункт, обсудить замену с преподавателем |
| Адаптивность | Карточки, диалог, помощник, мобильное и планшетное меню; светлая и тёмная темы |
| Практика skeleton screens | `CourseSkeleton.jsx`: заглушка повторяет структуру карточки и показывается во время настоящего запроса. Ошибка загрузки выводится отдельно |

## Что показать на защите

1. Открыть каталог без входа. Найти курс и открыть быстрый просмотр.
2. Отложить два курса: счётчик изменится. Перейти в избранное и обновить страницу.
3. Удалить один курс, затем очистить список: показать пустое состояние.
4. В каталоге выбрать по 3 курса на странице. Для демонстрации нескольких страниц нужны хотя бы 4 опубликованных курса; фиктивные курсы в рабочую БД не добавлялись.
5. Перейти на вторую страницу, применить поиск: страница сбросится на первую.
6. Открыть курс, затем войти и начать обучение. Показать хлебные крошки и прогресс.
7. На главной переключить советы. В помощнике задать вопрос об избранном.
8. В DevTools включить узкую ширину и медленную сеть, показать адаптивность и skeleton.

## Простая логика

- `FavoritesContext` — один общий список ID. Кнопки меняют список, а React перерисовывает счётчики и карточки. LocalStorage сохраняет его после обновления.
- `CoursesList` сначала фильтрует список, затем выбирает нужный участок через `slice`. Новых запросов при переключении страниц нет.
- `CoursePreview` запрашивает существующий API курса только при открытии. Нативный `dialog` удерживает клавиатурный фокус внутри окна.
- `LearningHelper` выбирает готовый ответ по вопросу или ключевым словам. Неизвестный вопрос направляет в обратную связь.
- `LearningPath` хранит индекс одного из трёх советов в `useState`.
