# Anki: темы до 10 октября 2026

Сборка берёт темы из календаря `learning_tracker` с датой не позднее
10.10.2026 и сверяет их с локальным `progress.json`.

```powershell
venv\Scripts\python.exe learning_tracker\anki_deck\build_deck.py
```

Результаты появляются в `output/`:

- `eidos_python_backend_through_2026-10-10.apkg` — основной пакет для Anki;
- `eidos_python_backend_through_2026-10-10.tsv` — резервный открытый формат;
- `README.md` — фактический состав конкретной сборки.

## Импорт на телефон

1. Сначала синхронизировать текущую коллекцию телефона с AnkiWeb.
2. Передать `.apkg` на телефон и открыть файл через AnkiMobile или AnkiDroid.
3. Убедиться, что появились подколоды `Eidos::До 10 октября`.
4. Снова выполнить синхронизацию с AnkiWeb.

Пакет имеет имя обычной колоды, а не `collection.colpkg`, поэтому он должен
добавлять материал к коллекции, а не заменять её. У заметок стабильные GUID:
повторная сборка и импорт предназначены для добавления новых карточек и
обновления существующих без сброса истории повторений.

Рекомендуемый первый проход: фильтровать по тегу `completed`, а темы 9–10
октября подключать после урока. Карточки дополняют практику, но не заменяют
написание кода, SQL-запросов и тестов без подсказки.
