# Объекты, ссылки и identity: обработать набор данных

## Условие
Расширьте задачу «два имени ссылаются на один список progress, после append изменение видно через оба имени». Обработайте последовательность входов за один проход. Не используйте вложенный полный перебор, если результат можно накопить через dict, set, deque, heap или сортировку.

## Что сдать
Решение пакетной или потоковой версии для Python. Файлы: solution.py + README.md; команда запуска записана в README.

## Проверки
- [ ] Все 10 входов обработаны одним запуском.
- [ ] Результат воспроизводится командой: py solution.py.
- [ ] В README указана сложность или число основных операций.
